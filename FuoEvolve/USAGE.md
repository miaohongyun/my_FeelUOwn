# FuoEvolve 使用手册（Android）

本手册对应手机端 APK（应用 ID `org.feeluown.mobile`）。桌面端（Windows / macOS / Linux）的安装与打包见 [README.zh-CN.md](README.zh-CN.md) 与 `docs/desktop-*.md`。

> 本应用只使用各音源自身提供的公开接口，按你的账号权限、地区和歌曲授权提供内容；不解锁会员、不绕过 DRM，也不保证热门歌曲都能免费听或免费下无损。

---

## 1. 安装与首次启动

### 安装

- 已构建的调试包：`androidApp/build/outputs/apk/debug/androidApp-debug.apk`
- 自行构建：项目根目录执行 `gradlew.bat :androidApp:assembleDebug`
- 安装时需允许「安装未知来源应用」；应用 ID 为 `org.feeluown.mobile`

### 首次启动引导

1. **选择音乐来源**：默认勾选网易云音乐、QQ 音乐、哔哩哔哩；YouTube Music 在列表里可选，但不默认启用（能否使用取决于你所在地区的网络）。
2. **配置智能替换**：可以选「智能替换」或「跳过」，并指定哪些音源只作为替换候选。
3. **登录账号**：可以点「稍后登录」先试用。未登录时仍能搜索和播放大部分试听内容，但高音质档位会受账号权限限制。

引导结束后，设置项都可以在「设置」里改。

## 3. 音源与账号

**设置 → 音源与账号**

- **启用/停用**：关掉的音源不再出现在搜索、推荐和替换候选中。
- **排序**：拖动调整顺序，顺序会影响聚合搜索的展示优先级和替换候选顺序。
- **登录**：每个音源支持自身的登录方式（网页登录、Cookie、请求头、OAuth，具体取决于该音源）。登录状态保存在本机。
- **显示与参与范围**：可以分别控制某个音源是否参与「搜索 / 推荐 / 探索 / 我的 / 智能替换」。
- **登录凭证备份**：可导出全部凭证到文件，或从文件恢复；也可只导出单个音源。凭证含账号信息，请自行妥善保管。
- **播放数据上报**：部分音源会把播放行为回传给它自己的服务端，可在此关闭。

> 升级提示：如果你是从旧版本升级，且之前手动保存过音源配置，新默认值不会覆盖你的设置。只在「设置 → 音源与账号」里手动启用即可。

## 4. 搜索与发现

- **统一搜索**：一次查询并发请求所有已启用音源，按音源分组展示。
- **单个音源失败不影响其他音源**：某个音源超时或报错时，其余音源的结果照常显示，失败原因归属到对应音源卡片。
- **慢音源超时**：单个音源响应过慢会被跳过，不会拖住整个搜索页。
- **详情页**：歌曲、专辑、歌单、歌手、视频均可进入详情；视频详情支持哔哩哔哩多分 P 切换。

## 5. 播放

### 5.1 队列与循环

- 队列来源可以是单曲、专辑、歌单、搜索结果或「下一首播放」。
- 循环模式：**不循环 / 全部循环 / 单曲循环**。
- 支持随机播放、进度跳转、上一首/下一首。
- 打开「其他应用播放时自动暂停」后，检测到别的应用开始发声会暂停当前播放。

### 5.2 音质

**设置 → 播放与音质 → 音质**

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| Wi‑Fi 音质 | 最高可用 | 连接 Wi‑Fi 时优先请求的档位 |
| 蜂窝网络音质 | 最高可用 | 使用移动数据时优先请求的档位 |

四档含义：

| 档位 | 策略值 | 说明 |
| --- | --- | --- |
| 最高可用 | `>>>` | 请求该音源最高档；歌曲没有无损时按音源能力回落 |
| 高音质 | `hq<>` | 常见 320kbps 档 |
| 标准音质 | `sq<>` | 常见 192kbps 档 |
| 省流量 | `lq<>` | 常见 128kbps 档 |

「最高可用」不等于每首歌都是无损：**它只表示请求该音源能给到的最高档**。实际能拿到什么，取决于你的账号权限和这首歌的授权。

播放页的音质标签来自结构化信息（音源声明、账号实测、容器/播放引擎确认），不是只看字符串。点开「音频信息」可以看到采样率、位深、声道与码率。

### 5.3 智能替换

**设置 → 播放与音质 → 智能替换**

当前歌曲在原音源无法播放（下架、无版权、取流失败）时，从你勾选的音源里找可播放的版本。

- **替换音源**：勾选参与替换的音源，会自动排除歌曲自身来源。
- **匹配严格度**：默认 `0.55`，可选预设或拖动自定义。分数越高越严格，越不容易接受差异较大的版本。
- **版本校验是双向的**：请求录音室版不会换成 Live 版，请求 Live 版也不会退回录音室版；翻唱、伴奏、Remix、Acoustic、Demo、变速、重制同样按版本冲突处理。
- **同名不同歌手会被拒绝**：歌手匹配分低于阈值时不做替换；候选缺少歌手信息时视为「未知」而非「不匹配」，交由总分判定。
- **B 站候选**：标题优先、标签兜底，避免把「翻唱投稿」当成原曲。

### 5.4 睡眠定时

播放页 → 睡眠定时：预设 15 / 30 / 45 / 60 / 90 / 120 分钟，也可自定义 1–1440 分钟。到点自动暂停。

### 5.5 歌词

**设置 → 外观与显示 → 播放显示**

- 同步歌词、翻译、罗马音，音源支持时显示逐字歌词。
- 可手动为当前歌曲匹配其他歌曲的歌词。
- **状态栏歌词**：通过词幕在系统状态栏显示当前歌词。
- **蓝牙车载歌词**：蓝牙输出时用媒体标题显示歌词；兼容模式可能影响其他系统媒体控制器。
- **比亚迪仪表歌词**：把歌词同步到驾驶仪表的三行区域。
- **关闭波形动画**：所有进度条改为普通直线样式。

## 6. 无损增强

没有会员时，普通音源通常只给 128kbps / 320kbps 的有损音频。开启无损增强后，应用会：

1. 依次到以下来源检索同标题、同歌手的 FLAC 原始文件：
   - **Navidrome / Subsonic 自建曲库**（优先级最高，支持局域网 `http://IP:4533` 直连）
   - **Jamendo**（国内可直连，内置免费 client_id）
   - **Internet Archive**（曲库大，国内多数网络无法直连）
2. 先校验文件头（FLAC 容器 + STREAMINFO），确认结构合法后立即开始播放；
3. 后台继续完整下载，用系统解码器解出 PCM 做 FFT 频谱分析；
4. 频谱检查未发现明显「低通断崖」时写入本地缓存，下次播放直接使用。

**能力边界**：容器校验只能证明文件符合 FLAC 结构；频谱断崖检测是启发式筛查，能发现部分明显的有损转码，但不能证明文件来自原生无损母带，也不能保证识别所有伪无损。应用会区分「仅容器检查通过」和「频谱启发式检查通过」，并在质量标签中体现。

### 设置

**设置 → 播放与音质 → 无损增强**

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 自动寻找 FLAC 高音质源 | 开 | 音源不是已识别的无损格式时，到开放曲库查找 FLAC 候选；需要联网 |
| 播放时预取下一首 | 开 | 听当前歌曲时提前准备队列中的下一首 |
| 仅 Wi‑Fi 下预取 | 开 | 移动网络下不自动预取整首无损 |
| 首次等待上限 | 10 秒 | 可选 5 / 10 / 15 / 20 秒；超时先用原音源，后台继续下载 |
| Jamendo 无损源 | 内置 client_id | 开箱即用；可改成自己的，留空保存恢复默认 |
| Navidrome / Subsonic 曲库 | 未配置 | 填服务器地址、用户名、密码后启用；没有自建服务可点「填入官方演示」用 `demo/demo` 测试 |

关闭「自动寻找 FLAC 高音质源」后，播放和下载都不再做替换。

### 播放时的行为

- **命中缓存**：直接播放本地 `file://` 的无损文件，无网络等待。
- **首次播放**：最多等待「首次等待上限」；找到候选就先播远端 FLAC，同时后台下载并校验。
- **等待超时**：立刻用原音源播放，不阻塞；后台任务继续，成功后写入缓存，下次播放生效。
- **已经是无损**：本地文件、`.flac` 地址或音质标记为无损时不再重复替换。
- **来源互不影响**：某个来源连不上只让它自己退避，不影响其他来源。

## 7. 下载

### 下载前选音质

在歌曲、专辑或歌单里点「下载」，会先弹出音质选择：

1. **正在检测可用音质**：正在向音源确认当前账号能取到哪些档位；
2. 探测完成后只显示**真正可用**的档位，并按音源能力隐藏不可用项；
3. 标题下方会说明为什么档位变少了，例如「已按当前账户的实际权限隐藏不可用档位」；如果当前账号一档都取不到，会提示换音源或稍后重试；
4. 选择「无损 / 最高可用」时会先尝试获取 FLAC 候选（最长约 35 秒），通过校验后下载；找不到或校验失败时回退到音源自身最高档，不会让下载失败。

「跟随设置」表示使用「设置 → 播放与音质」里的默认音质。

> 免费账号看到「无损」档不代表真能取到无损。本版本会在打开弹窗前做账号维度的实测：网易云以账号的下载/播放权限字段为准，QQ 音乐逐档探测 vkey，取不到就不显示该档。

### 下载管理

**设置 → 下载与存储 → 下载管理**

- 任务状态：等待下载 / 下载中（显示已下载字节）/ 已暂停 / 失败 / 已完成。
- 支持暂停、继续、重试、删除；删除时可勾选「同时删除本地文件」。
- 支持断点续传：暂停或中断后从已下载部分继续。
- 可设置并行下载数量。
- 下载文件保存在系统「音乐」目录下的 `FeelUOwn` 子目录（Android 10 及以上走系统媒体库，卸载应用不会删除这些文件）；歌词与索引保存在应用私有目录。

## 8. 投屏（设备投放）

播放页右上角的投屏图标可以搜索同一 Wi‑Fi 下的电视 / 音箱（DLNA 渲染器），点设备名即可开始投放。

- **整队列连播**：电视播完一首后，手机端自动把队列里的下一首推给电视，不需要再操作。
- **手机静音**：投放期间手机本地播放被静音，避免手机和电视同时出声；停止投放后恢复原来的音量。
- **面板里的暂停/播放、下一首只控制电视**：暂停后再切歌，电视仍保持暂停，不会突然自己响起来。
- **队列播完**：电视停下，面板提示「队列已经播完了」，不会留下无声的投放会话。
- **误判保护**：部分电视在打开流的过程中会先报 `STOPPED`，这种情况会被忽略；只有在见过播放状态之后才认「播完」。
- **位置兜底**：少数电视播完仍报 `PLAYING`，此时以「位置到末尾且连续两次不变」作为播完依据，避免把最后两秒切掉。

要求：

- 手机与电视在同一局域网；部分路由器开启了「AP 隔离」会导致搜索不到设备。
- 电视需支持 DLNA / 媒体投放（大部分智能电视和电视盒子都支持）。
- 局域网明文 HTTP 已针对投屏放行，不需要额外配置。
- 桌面端与 iOS 端目前没有投屏实现，按钮不会出现可投放设备。

## 9. 本地音乐与歌单

**首页 → 我的 → 本地音乐**

- 扫描系统媒体目录，支持多目录；可设置「忽略短音频」的时长阈值。
- 视图：全部 / 按歌手 / 按专辑。
- 可编辑单曲元信息（标题、歌手、专辑等）。
- 可创建本地歌单并增删歌曲。
- 需要在系统里授予媒体读取权限；封面显示需要图片读取权限。

**在线歌单**：音源支持时可收藏、创建、增删歌曲；不同音源的权限范围不同，界面会按能力显示。

## 10. 听歌识曲

首页搜索栏旁的识曲入口：录一段正在播放的音乐，应用会做识别并给出匹配结果，可以直接进入搜索或歌曲详情。

- 需要麦克风权限；
- 环境嘈杂或音乐太短时识别率会下降；
- 识别结果只是候选，最终以播放页实际能否取流为准。

---

## 11. 歌单迁移

**我的 → 歌单迁移**

流程：选择来源歌单 → 选择目标平台 → 自动找歌 → 核对匹配 → 选择/创建目标歌单 → 迁移 → 查看记录。

- 只展示支持「向歌单添加歌曲」的平台；候选只来自所选目标平台。
- 支持创建歌单的平台提供「创建并迁移」；不支持创建时，引导你先在对应平台建好再刷新选择。
- **来源歌单不会被修改**。
- 转换（读取、匹配）与写入分成两个阶段：必须停在「检查匹配」等你确认，之后才开始写入。
- 中断后从检查点继续，不会重复提交已经成功的写入；结果不明确时先回读目标歌单核对，不盲目重发。
- Android 使用带网络约束的后台任务与前台进度通知；拒绝通知权限不影响迁移，只是看不到进度通知。

## 13. 缓存、存储与更新

- **无损缓存**：应用私有目录 `files/lossless`，上限 **1.5GB**，超出后按最早校验时间淘汰。
- **音频 / 图片缓存**：在「设置 → 下载与存储 → 缓存」里分别设上限，可查看当前占用并清理。
- **下载文件**：`Music/FeelUOwn`；删除应用数据或卸载应用都不会删除这些文件。
- **应用更新**：Stable 偏稳定，Canary 更新更早但可能不稳定。可在应用内检查、下载并安装；安装需要「允许安装未知应用」权限。桌面端暂不接入应用内自动更新。

---

## 14. 网络与地区限制

- **Jamendo**：国内可直连，client_id 已内置。
- **Navidrome / Subsonic**：支持 `http://` 与 `https://`；手机与 NAS 需在同一网络。官方演示 `https://demo.navidrome.org`（`demo/demo`）仅用于验证链路，曲库很小且可能随时关停。
- **Alist / 群晖 WebDAV**：暂未接入 Subsonic 协议检索；有单曲直链可走「自定义播放地址」。
- **Internet Archive**：依赖 `archive.org`，国内多数网络无法直连。
- **YouTube Music**：依地区与网络可达性而定，默认不启用。
- **失败退避**：单个无损来源网络失败后 3 分钟内跳过；单曲 10 分钟内不重复检索。

## 15. 故障排查

### 看日志

1. 手机开启开发者选项与 USB 调试，连接电脑；
2. 执行 `adb logcat | findstr Lossless`（Windows）或 `adb logcat | grep Lossless`；
3. 常用标签：`LosslessEnhancer`、`LosslessSubsonic`、`LosslessJamendo`、`LosslessArchive`、`LosslessValidator`、`LosslessCache`。

应用内也提供「设置 → 关于 → 应用日志」，可直接查看调试日志与错误信息。

### 常见现象对照

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 搜索只有一两个音源有结果 | 其他音源未登录、被停用或超时 | 到「音源与账号」确认启用与登录状态 |
| 音质弹窗档位很少 | 免费账号权限受限，或该歌曲本身没有高码率版本 | 看弹窗顶部的说明文字；登录会员账号后重试 |
| 无损增强几乎不命中 | 开放曲库以独立音乐和现场录音为主 | 自建 Navidrome/Subsonic 是最现实的办法 |
| 投屏搜索不到电视 | 不在同一网段、路由器 AP 隔离、电视未开投屏 | 关掉 AP 隔离，确认电视的投屏/媒体共享已开启 |
| 投屏一首后停下 | 旧版本行为 | 升级到包含连播的版本；仍复现请提供电视型号 |
| 下载卡在「等待下载」 | 并行下载数量已满 | 调大并行数或等待前面的任务结束 |

## 16. 常见问题

**Q：为什么很多歌还是原音源？**
开放曲库以独立音乐和现场录音为主，主流华语流行基本不在其中。匹配不到时会按超时策略回退，不影响正常播放。想提高命中率只能靠自建曲库。

**Q：国内还有别的开放曲库吗？**
主流平台（网易云、QQ 音乐、酷狗等）没有合规的无损开放接口；网易云外链只有 128kbps，只适合测试播放链路。想要稳定的无损来源，最现实的是自建 Navidrome 或使用支持 Subsonic 协议的服务。

**Q：自建曲库怎么配置？**
1. 在 NAS/PC 上用 Docker 部署 Navidrome，扫描存放 FLAC 的目录；
2. 设置里填 `http://NAS的IP:4533`、账号、密码，保存即启用；
3. 播放时先去自建曲库按标题 + 歌手检索 FLAC，命中且校验通过即替换播放；
4. 没有 NAS 时可点「填入官方演示」用 `demo/demo` 先验证链路。

**Q：如何判断是不是原生无损？**
应用会校验 FLAC 容器与 STREAMINFO；Android 能解码时还会做频谱断崖启发式检测。该检测只能识别部分明显的有损转码，不能证明源文件来自无损母带。设备不支持该解码格式时只做容器校验，并在质量标签中注明。

**Q：预取会不会很耗流量？**
默认「仅 Wi‑Fi 下预取」；移动网络下只在你主动播放时最多等 10 秒，超时即用原音源。

**Q：下载的无损在哪里？**
与普通下载共用 `Music/FeelUOwn`；无损缓存另存于应用私有目录，仅用于加速后续播放。

**Q：为什么投屏时手机没声音？**
这是刻意设计：投屏期间手机被静音，但播放队列仍在推进，用来驱动电视连播。停止投放后音量自动恢复。

**Q：使用是否涉及版权？**
开放曲库内容遵循其各自的授权协议，请仅用于个人合法用途。
