# my_FeelUOwn

FeelUOwn 相关代码的个人集合，包含以下四个子项目：

| 目录 | 说明 |
|---|---|
| `FeelUOwn/` | 桌面版 FeelUOwn（Python + PyQt6），与上游 feeluown/FeelUOwn v5.1.3 一致 |
| `FuoEvolve/` | 移动端（Kotlin + Compose Multiplatform），含本地改造：下载选音质、DLNA 投屏、连播等 |
| `feeluown-cast/` | 桌面端 DLNA 投屏插件（本地改造） |
| `feeluown-download/` | 下载插件，含下载前选音质功能（本地改造） |

本仓库仅用于个人代码备份与同步。
