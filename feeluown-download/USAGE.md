# fuo_dl 使用说明

> 适用平台：桌面版 FeelUOwn（Windows / macOS / Linux）。
> 当前仓库只包含桌面端插件实现，手机 APK 不会加载这份代码，
> 因此下载、真无损校验、播放补无损等功能不会自动出现在手机上。

面向使用者的操作手册。装好后不需要写代码，日常只用右键菜单和配置项。

## 1. 它能做什么

- **下载歌曲**：右键选音质下载，自动写入 ID3 标签，已存在则跳过。
- **真无损校验**：识别「有损转码冒充 FLAC」和「假 Hi-Res」，不是只看后缀。
- **下载时补无损**：商业音源给不了无损时，自动去开放曲库找同名版本让你挑。
- **播放时补无损**：原音源是有损流时，播放前自动换成开放曲库的无损文件并缓存。
- **自定义播放地址**：自己贴 http/https 直链或本地文件，保存后随时点播。

它**不**做会员破解，也**不**对接盗版解析接口。原音源能拿到什么品质，最终仍取决于你登录的账号权限；插件只做两件事：把已有权限里的最高品质取出来，以及在合法开放曲库里找替代音源。

## 2. 安装与启用

前置条件：

| 依赖 | 用途 | 是否必须 |
|---|---|---|
| FeelUOwn 可正常启动 | 运行环境 | 必须 |
| `ffmpeg` / `ffprobe` 在 PATH 中 | 真无损校验 | 强烈建议 |
| `numpy` | 频谱分析加速 | 可选 |

安装方式二选一。

**方式 A：pip 安装（推荐）**

```bash
cd e:\mypro\feeluown-download
python -m pip install -e .
```

**方式 B：放进插件目录**

把整个 `fuo_dl` 目录复制到 `C:\Users\<你的用户名>\.FeelUOwn\plugins\fuo_dl`，
确保该目录下直接就是 `__init__.py`（不要多套一层）。

重启 FeelUOwn，插件会自动加载，插件列表里显示为「音乐下载」。日志中出现下面两行即挂载成功：

```
fuo-dl init
fuo-dl 播放桥已挂载，缓存目录：...
```

## 3. 下载歌曲

1. 在歌曲列表里右键任意歌曲 →「下载歌曲」；也可以点播放栏上的下载按钮下载当前歌曲
   （文件已存在时按钮会置灰并显示为已勾选）。
2. 弹出音质选择框，列出的都是**这首歌实际可用**的档位，按品质从高到低排：

   | 选项 | 含义 |
   |---|---|
   | 无损 / 超高品质（>320kbps，通常需要会员） | shq |
   | 高品质（约 320kbps） | hq |
   | 标准品质（约 200kbps） | sq |
   | 流畅品质（约 100kbps） | lq |

   最后一项是「默认音质（跟随播放策略，不指定档位）」。不想选就选它。
3. 点「取消」则本次不下载。

几个细节：

- 多选批量下载只弹一次框，用第一首歌的档位代表整批。
- 如果音源本身不提供多档音质，不会弹框，直接按播放策略取流。
- 下载完成后会自动校验真无损，结果以状态栏提示为准。
- 底部状态栏会显示下载进度。

**文件命名**：默认 `{title}__{artists}__{album}__{kbps}__{duration_ms}.{ext}`，
空值用 `unknown` 填充。选了具体音质档位时，文件名末尾会追加 `_shq` / `_hq` 这类后缀，
避免不同音质互相判定成「已下载」。

**下载目录**：默认 `C:\Users\<你的用户名>\.FeelUOwn\songs`，改 `DOWNLOAD_DIR` 即可（见第 8 节）。

## 4. 下载时自动补无损

当你选的音质不是无损（或原音源根本取不到流）时，插件会拿「标题 + 艺人」去开放曲库搜一遍。

流程与界面提示：

1. 状态栏提示「当前音源不是无损，正在检索开放曲库…」。
2. 找到候选时弹框「选择无损音源」，每行显示 `序号. 艺人 - 标题 [来源 | 大小]`。
3. 选中后开始下载，提示「正在下载无损：艺人 - 标题」。
4. 下载完提示「下载完成｜校验结果」；校验不通过会追加「该文件未通过真无损校验，建议不要当作无损收藏」。
5. 没有候选时提示「开放曲库没有匹配的无损版本，按原音质下载」，此时按你选的音质正常下载。
6. 可以选「跳过，按原音质下载」。

覆盖范围：

| 音源 | 内容 | 是否需要配置 |
|---|---|---|
| Internet Archive | 公共领域录音、现场、古典 | 不需要 |
| Jamendo | 独立音乐、CC 授权作品 | 需要免费 `client_id` |

**主流流行专辑基本搜不到**，这部分仍然只会下到商业音源提供的有损品质。匹配规则偏保守，
宁可漏掉也不下翻奏版或同名不同曲。

## 5. 播放时自动用无损

插件挂载后会接管取流，按以下顺序处理：

1. **之前缓存过无损文件** → 直接播本地文件，不发任何网络请求。
2. **原音源本身就是无损**（flac/alac/wav 等）→ 原样播放，不做任何额外动作。
3. **原音源是有损流** → 去开放曲库找同名曲目，下载并校验。
   - 第一次播放会**等它准备好再播**，默认最多等 **10 秒**，状态栏提示「正在准备无损音源，最多等待 10 秒…」。
   - 10 秒内没下完，提示「无损音源还没准备好，先按原音质播放，后台会继续缓存」，
     先按原音质播放，下载任务继续跑，**下次播放直接用缓存**。

**下一首预取**：当前歌曲一开始播放，插件就会在后台为**下一首**准备无损
（默认开启）。等切到下一首时通常已经命中缓存，直接零等待播放。
原音源本身无损的歌会跳过预取，不浪费流量。

等这么久是因为一首 FLAC 动辄几十 MB。嫌慢就调小等待时间，设成 0 表示完全不等：

```python
config.fuo_dl.PLAY_WAIT_TIMEOUT = 0
config.fuo_dl.PLAY_PREFETCH_NEXT = False   # 手机流量紧张时可以关掉预取
```

**缓存位置**：`C:\Users\<你的用户名>\.FeelUOwn\cache\fuo_dl\lossless`
索引是同目录下的 `index.json`，重启后仍然有效。文件被手动删除的条目会在下次启动时自动剔除。

**清缓存**：退出 FeelUOwn，删掉整个 `fuo_dl\lossless` 目录即可。缓存只影响播放，不影响已下载的歌曲。

## 6. 自定义播放地址

开放曲库覆盖不到的歌，可以自己贴地址。

1. 歌曲列表右键 →「播放自定义音频地址…」。
2. 弹框里选一条已保存的地址直接播放，或者选「＋ 新增音频地址…」。
3. 新增时粘贴 `http/https` 音频直链，或输入本地文件路径（支持 `~` 和环境变量展开）。
4. 想删除就选「－ 删除已保存地址…」，再从列表里挑一条。

限制与行为：

- 只接受 `http` / `https` 直链和**真实存在**的本地文件；`ftp`、`magnet` 等协议会被拒绝。
- 保存到 `C:\Users\<你的用户名>\.FeelUOwn\data\fuo_dl\custom_media.json`，重启后仍在。
- 播放自定义地址时，播放栏的下载按钮：网络直链可点，下载的就是该地址本身，文件名取地址里的文件名；
  本地文件地址按钮禁用（文件已经在你本机了）。
- 这条路径只负责播放和记录，不解析来源、不绕过会员。

**预置测试音源**（首次使用自动写入，用来验证播放/下载链路是否通）：

| 标题 | 来源 | 许可 |
|---|---|---|
| FLAC 真无损测试（CC0 / IETF CELLAR） | IETF CELLAR FLAC test files（经 jsDelivr） | CC0 1.0 |
| Kevin MacLeod - Mesmerizing Galaxy | incompetech.com | CC BY 4.0 |
| Kevin MacLeod - Lord of the Rangs | incompetech.com | CC BY 4.0 |
| Kevin MacLeod - Adeste Fideles | incompetech.com | CC BY 4.0 |

第一条是标准 FLAC，可用于确认「真无损」校验是否正常工作；后三条是有损 MP3，
可用于观察「非无损 → 检索开放曲库」的提示。CC BY 条目如需二次分发请保留作者署名。
测试完可在菜单里直接删掉，删掉的条目不会在下次启动时复活。

## 7. 真无损校验怎么看

校验分三层，不只看扩展名：

1. **容器层**：编码本身是 mp3/aac/opus → 有损源。
2. **频谱层**：有损转码会在截止频率处留下几十 dB 的陡崖（常见于 20.3–20.4kHz），真实录音是连续滚降。
3. **位深层**：声称 24bit 但只有 16bit 有效精度 → 假 Hi-Res。

结论含义：

| 结论 | 含义 | 处理 |
|---|---|---|
| 真无损 | 三层都通过 | 正常保存/缓存 |
| 可疑 | 老录音自然滚降，无法确定但不像转码 | 允许，但不建议当严格无损收藏 |
| 假无损 | 检测到转码断崖或假位深 | 播放不缓存；下载会提示不要当无损收藏 |
| 有损源 | 文件本身就是 mp3/aac 等 | 同上 |
| 无法解析 | 没装 ffmpeg，或文件损坏 | 只按编码格式判断，不报错 |

报告是单行文本，形如 `真无损 | FLAC 44.1kHz/16bit | 截止 22.0kHz`，
包含编码、位深/采样率、频谱截止频率和首条判定理由。

## 8. 配置速查

配置文件是 `C:\Users\<你的用户名>\.fuorc`（Python 语法），改完重启 FeelUOwn 生效。
两种写法等价：`config.fuo_dl.XXX` 和 `config.dl.XXX`。

```python
# 下载目录
config.fuo_dl.DOWNLOAD_DIR = r'D:\Music'

# 首次播放最多等 10 秒；0 表示不等，后台准备、下次播放生效
config.fuo_dl.PLAY_WAIT_TIMEOUT = 0
```

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `DOWNLOAD_DIR` | `~/.FeelUOwn/songs` | 下载保存目录 |
| `ASK_QUALITY` | `True` | 下载前弹音质选择框；关闭后按播放策略取流 |
| `VERIFY_LOSSLESS` | `True` | 下载完成后做真无损校验 |
| `OPEN_SOURCE_FALLBACK` | `True` | 下载时原音源不是无损就去开放曲库找 |
| `PLAY_OPEN_SOURCE_FALLBACK` | `True` | 播放时自动补无损并缓存 |
| `PLAY_WAIT_TIMEOUT` | `10` | 首次播放等待无损音源的秒数，`0` 表示不等待 |
| `PLAY_PREFETCH_NEXT` | `True` | 播放时后台预取下一首，切歌通常零等待 |
| `JAMENDO_CLIENT_ID` | `""` | Jamendo 免费 client_id；留空只搜 Internet Archive |
| `NAME_FORMATS` | `[]` | 自定义命名模板列表，见下 |
| `CORE_LANGUAGE` | `"auto"` | 标签语言：`auto` / `ch`（简）/ `tc`（繁），转换需 `pip install inlp` |
| `ENABLE_V2` | `False` | 启用新版下载 UI（只兼容 v2 model） |

`NAME_FORMATS` 按优先级填写，支持 `albumartist` / `album` / `artist` / `title` / `track`：

```python
config.fuo_dl.NAME_FORMATS = [
    '{albumartist}/{album}/{track} {title}',
    '{artist}/{title}',
]
```

## 9. 常见问题

**Q：为什么周杰伦、Taylor Swift 搜不到无损？**
开放曲库只有公共领域和 CC 授权作品。商业流行专辑的无损必须来自你已登录的音源账号权限，
插件无法凭空变出来，也不会去接盗版解析接口。

**Q：每次播放都要等 10 秒，太慢。**
只有「原音源有损 + 缓存里没有」的第一次会等。保持 `PLAY_PREFETCH_NEXT` 开启，
听当前歌时下一首已经在后台准备好，切歌后基本不用等。也可以把 `PLAY_WAIT_TIMEOUT` 调成 5，
或设成 0 让它后台准备；同一首歌第二次播放直接用缓存。

**Q：设了 0 之后还是没听到无损？**
第一次播放按原音质出声，后台下完后，第二次播放才生效。看状态栏是否提示「无损音源还没准备好」。

**Q：怎么确认无损真的生效了？**
看缓存目录 `...\.FeelUOwn\cache\fuo_dl\lossless` 里是否出现对应文件，以及日志里的
「使用缓存的无损音源」。也可以右键下载后用第 7 节的结论核对。

**Q：下载完成提示「该文件未通过真无损校验」。**
说明开放曲库里这条资源本身是转码的，建议删掉换一个候选版本。播放缓存遇到这种文件会自动丢弃。

**Q：右键没有「下载歌曲」或「播放自定义音频地址…」。**
插件没加载成功。检查 `fuo_dl` 是否在插件目录、依赖是否装全，看日志里有没有
`Enable plugin:fuo_dl failed`。

**Q：点了下载没有弹音质选择框。**
该音源不支持多档音质查询，此时按播放策略取流，属于正常行为。

**Q：自定义地址播不了。**
先确认是音频文件的直链（不是网页地址），`http/https` 能直接返回音频内容；
本地路径必须真实存在。magnet、ftp、网盘分享页都不支持。

**Q：Jamendo 怎么启用？**
到 `https://devportal.jamendo.com` 免费申请 `client_id`，填到 `JAMENDO_CLIENT_ID`。
不填也能用，只是少了 Jamendo 这部分候选。

**Q：校验提示「无法解析」。**
没装 ffmpeg/ffprobe，或文件损坏。把 ffmpeg 的 `bin` 目录加进 PATH 后重启；
不装也能用，只是只按编码格式判断。

**Q：预取会不会偷偷跑很多流量？**
每首歌只预取一次「下一首」，且下一首本身是无损时直接跳过；失败或没有候选也不会反复重试。
流量紧张或使用手机热点时，设 `PLAY_PREFETCH_NEXT = False` 即可关闭。

**Q：会不会占很多磁盘？**
播放缓存按歌曲累积，一首无损通常 20～50MB。定期清理
`...\.FeelUOwn\cache\fuo_dl\lossless` 即可，不影响下载目录里的文件。

## 10. 使用边界

- 插件只读取你**已有权限**能拿到的音质，不做会员绕过、不调用第三方破解接口。
- 开放曲库只覆盖公共领域和 CC 授权作品；下载后如需公开传播，请遵守对应许可
  （CC BY 需署名，CC0 可自由使用）。
- 自定义播放地址由你自己提供，请确保你有权访问和播放该地址的内容。
- 请遵守所用音乐平台的服务条款，下载内容仅限个人合理使用。
